# 猫粮数据工作台 · Pet Food Data Studio

把猫粮产品、配方营养、品牌与工厂资料放到一起，查找和比较时少来回翻。

由 **査老师的宠物小灶** 维护，面向需要选粮、对比配方和了解品牌背景的养宠人。

**[打开工作台](https://charlesy520.github.io/pet-food-data-studio-public/)**

## 可以做什么

| 功能 | 用途 |
| --- | --- |
| 产品查找与筛选 | 按品牌、工艺、阶段、进口属性、功能、生产方式、价格和营养范围查找；支持配料及描述关键词筛选。 |
| 营养与价格图表 | 切换比较指标，查看产品分布、价格区间和同位置的多款产品。 |
| 产品完整详情 | 查看配料、营养添加剂、保证值、规格价格、工厂，以及功能和喂养研究资料。 |
| 多款横向比较 | 勾选产品，并列对照价格、营养、配方、功能与生产信息。 |
| 偏好与权重 · 测试中 | 按自己的配料、生产方式、工艺和预算偏好调整权重，查看试评分及资料覆盖情况。 |
| 品牌与工厂情报库 | 查看品牌背景、定位与市场资料、工厂信息和来源分级，支持与产品详情互相跳转。 |
| 核心产品快捷筛选 | 一键查看维护者人工确认的核心产品，便于缩小比较范围。 |

支持电脑和手机浏览；电脑更适合多指标查看与横向比较，手机可用产品卡片查找、查看详情和加入比较。

## 怎么开始

1. 打开工作台，按品牌、预算或适用阶段缩小范围。
2. 点“详情”读配料和保证值，再点品牌或工厂入口查看背景。
3. 勾选两款或多款产品，进入横向比较；有需要再试“偏好与权重”。

核心产品由维护者确认，公开版只读，访客不能修改产品资料或核心标记。

## 阅读数据时

- 资料整理自网络公开信息和品牌、产品页面；价格为记录快照，购买时请核对实际渠道、规格和活动。
- 营养保证值的 ≥ / ≤ 表示下限 / 上限，通常不是实测值；不同阶段、单位和干物质基准应分别核对。空白不代表零。
- 功能定位、页面引用的喂养研究和独立验证是不同层次，请结合详情中的对象、范围与出处阅读。
- 权重模块仍在测试，分数表示当前偏好下的试算结果，不是产品质量、安全或功效评级。

## 项目与更新

这是持续更新的公开只读版。内部资料审核后按批次同步，页面中的资料日期和数量以当次发布为准；不是实时价格服务。

本仓库包含网页运行文件及公开展示数据，浏览器可以读取、保存这些内容。内部 Excel 底稿、内部数据库、编辑后台和完整内部项目不在这里发布。页面暂不提供编辑、导入、导出或专门下载入口。
