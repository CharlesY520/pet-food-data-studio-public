# Pet Food Data Studio · 公开体验版

这是 Pet Food Data Studio 的阶段性只读体验版，用于体验宠物食品资料的查找、筛选、排序、营养分布和产品摘要比较。

## 使用边界

- 页面只读，不提供编辑、上传、导入、导出或下载入口。
- 页面中的价格、营养指标和功能资料是公开摘要记录，不构成营养合格判断、功效证明或购买推荐。
- “有资料记录”不等于该产品逐 SKU 的功效已经被独立实验确认。
- 浏览器能读取的公开摘要默认可能被保存或抓取；本仓库不包含内部 Excel、SQLite、完整内部数据、来源路径或维护信息。

## 数据来源原则

公开数据由内部事实主本按字段白名单单向生成。内部主本不放入本仓库；公开数据需要更新时重新生成本目录的 `data.js`。

## 项目状态

这是阶段性试用版本，不代表内部工作台已完成专业评分、全库功效核验或市场结论。
